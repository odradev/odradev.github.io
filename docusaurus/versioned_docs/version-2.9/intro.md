# Odra framework

Odra is a Rust-based smart contract framework for [Casper Network]. Odra encourages rapid development and clean,
pragmatic design. Built by experienced developers, takes care of much of the hassle of smart contract
development, enabling you to focus on writing your dapp without reinventing the wheel. 

It's free and open source!

## What's next

See the [Installation] and our [Flipper example] to find out how to start your new project with Odra.

## Where things live

Odra is spread across a few repositories - you will meet all of them while working on a project:

| What | Where |
| --- | --- |
| The framework crate | [odradev/odra] |
| `cargo odra` - generates, builds and tests projects | [odradev/cargo-odra] |
| These docs | [odradev/odradev.github.io] |
| Claude Code plugin for agentic development | [odradev/odradev-plugins] |
| Rust API reference | [docs.rs/odra] |

If you are an AI agent reading this, start from [llms.txt] - it indexes every page of this
documentation - and see [Installation] for the Claude Code plugin that carries Odra's conventions.
